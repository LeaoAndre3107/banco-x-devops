Projeto: Banco X Fase atual: 05 / 06 Cloud: AWS us-east-1 Atualizado: Maio 2026

Execute os passos na ordem apresentada. A AMI (ami-0f3a1a124baad0b82) e o secret do Secrets Manager não são destruídos pelo terraform destroy — eles persistem. Após o terraform apply, atualize o ALB URL no secret (Passo 03) e reinsira os dados do DynamoDB (Passo 04).

03
Atualizar secret no Secrets Manager importante
O ALB DNS muda após cada apply — o secret precisa ser atualizado

⚡ O secret bancox/dev/config persiste após o destroy. Só precisa atualizar o alb_url com o novo DNS.

Atualizar o ALB URL no secret
# Pegar o DNS atual automaticamente
ALB_DNS=$(cd /mnt/e/DEVOPS\ GUIADO/BANCO\ X/dev && terraform output -raw alb_dns_name)

# Atualizar o secret
aws secretsmanager update-secret \
  --secret-id "bancox/dev/config" \
  --secret-string "{
    \"alb_url\": \"http://$ALB_DNS\",
    \"cluster\": \"bancox-dev\",
    \"environment\": \"dev\",
    \"version\": \"1.0.0\"
  }"
Confirmar secret atualizado
aws secretsmanager get-secret-value \
  --secret-id "bancox/dev/config" \
  --query 'SecretString' \
  --output text

Build e push da imagem Docker
Recompilar e enviar a imagem da API para o ECR
Build, tag e push

08
Auditoria e relatórios de acesso novo
Consultar logs do CloudWatch — uso em auditorias fiscais e relatórios gerenciais
Ver todas as consultas registradas
aws logs filter-log-events \
  --log-group-name "/bancox/dev/api" \
  --filter-pattern "AUDITORIA" \
  --query 'events[*].message' \
  --output table
Filtrar por conta específica
aws logs filter-log-events \
  --log-group-name "/bancox/dev/api" \
  --filter-pattern "\"conta=12345-6\"" \
  --query 'events[*].message' \
  --output table
Substitua 12345-6 pelo número da conta desejada.
Consultas de hoje
aws logs filter-log-events \
  --log-group-name "/bancox/dev/api" \
  --filter-pattern "AUDITORIA" \
  --start-time $(date -d 'today 00:00:00' +%s000) \
  --query 'events[*].message' \
  --output table
Gerar relatório em arquivo (para entrega em auditoria)
aws logs filter-log-events \
  --log-group-name "/bancox/dev/api" \
  --filter-pattern "AUDITORIA" \
  --query 'events[*].message' \
  --output text > relatorio_auditoria_$(date +%Y%m%d).txt

cat relatorio_auditoria_$(date +%Y%m%d).txt
Consultar período específico (auditoria fiscal)
# Converter datas para Unix timestamp em milissegundos
START=$(date -d '2026-05-01' +%s000)
END=$(date -d '2026-05-31' +%s000)

aws logs filter-log-events \
  --log-group-name "/bancox/dev/api" \
  --filter-pattern "AUDITORIA" \
  --start-time $START \
  --end-time $END \
  --query 'events[*].message' \
  --output text > relatorio_maio_2026.txt
Verificar log streams ativos
aws logs describe-log-streams \
  --log-group-name "/bancox/dev/api" \
  --order-by LastEventTime \
  --descending \
  --max-items 5 \
  --query 'logStreams[*].{Stream:logStreamName,UltimoEvento:lastEventTimestamp}' \
  --output table
